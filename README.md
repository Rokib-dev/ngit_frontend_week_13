# Interactive To-Do List Application

A lightweight, responsive web application built with vanilla JavaScript, HTML5, and CSS3. This app allows users to create, manage, and delete daily tasks dynamically using DOM manipulation.

## Features

- **Add Tasks:** Quickly add new tasks via input field.
- **Mark Complete:** Click on any task item to toggle its completion status (strikethrough text).
- **Delete Tasks:** Remove individual tasks from the list with a single click.
- **Input Validation:** Prevents adding empty tasks to keep the list clean.
- **Clean UI:** Styled with a modern, centered layout and custom CSS styling.

## How to Run

1. Clone this repository or download it as a ZIP.
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.

No installation or server setup needed — it runs directly in the browser.

## Tech Stack

- **HTML5:** Semantic structure for list elements and input forms.
- **CSS3:** Custom layout styling, flexbox alignment, and state classes (`.completed`).
- **JavaScript (ES6):** Dynamic DOM creation, event delegation, and interactive state changes.
